# Proyecto Asistente De Voz Viernes

En este proyecto se compone de dos partes principales, el codigo de arduino para la ESP32S3 T Display Touch de Lillygo y el codigo del servidor php que procesa los datos

### Servidor PHP

En la carpeta `/servidor_php` Esta el codigo del servidor php para el procesamiento del asistente

### Codigo Arduino

En la carpeta `/viernes` esta el proyecto para el Arduino IDE para nuestra esp32s3 T Display Touch de Lillygo
